About MinuteGate

MinuteGate is an open-source protocol for paying per minute over HTTP 402. FanParking.Space and AIParking are the first applications built on it.

The project is under development. Payments shown in this repository run in the PayPal sandbox only; no real money moves.

MinuteGate is published under the Apache License, Version 2.0. The repository holds the protocol specification (SPEC.md), TypeScript source for a PayPal sandbox client and an example 402 server, examples, and tests.

Support comes from the community through GitHub Issues and discussions on the repository, on a best-effort basis. There is no paid or dedicated support. MinuteGate does not process, hold, or refund payments. Payments are handled by PayPal.
